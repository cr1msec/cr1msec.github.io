MetaTwo

HTBEasyWordPressSQLiCredential Abuse

MetaTwo was compromised through a SQL injection in a WordPress plugin, which exposed credentials that led to SSH access. Further enumeration uncovered Passpie credentials, allowing recovery of the root SSH password.

Solved: July 29, 2026

Recon

Started with a basic Nmap scan:

nmap
$ nmap -sC -sV -Pn 10.129.228.95

Open ports:

PortService
21FTP
22SSH
80HTTP

The web server was running nginx and redirected to metapress.htb.

Enumeration

The website was running WordPress 5.6.2 with PHP 8.0.24.

WordPress enumeration revealed two users:

  • admin
  • manager

Two outdated plugins were identified, including bookingpress-appointment-booking version 1.0.10.

The BookingPress plugin was vulnerable to SQL injection. Using the Metasploit module wp_bookingpress_category_services_sqli, WordPress password hashes were extracted:

admin : $P$BGrGrgf2wToBS79i07Rk9sN4Fzk.TV. manager : $P$B4aNM28N0E.tMy/JIcnVMZbGcU16Q70

The manager hash was cracked:

manager : partylikearockstar

Further enumeration exposed the WordPress configuration file, which contained FTP credentials:

FTP_USER: metapress.htb FTP_PASS: 9NYS_ii@FyL_p5M2NvJ FTP_HOST: ftp.metapress.htb

The application configuration also contained SMTP credentials for jnelson:

Username: jnelson@metapress.htb Password: Cb4_JmWM8zUZWMu@Ys

Initial Access

The discovered jnelson credentials provided SSH access:

ssh
$ ssh jnelson@10.129.228.95

After gaining access as jnelson, further enumeration revealed a .passpie directory containing a PGP key pair and encrypted Passpie data. The Passpie private key was recovered and cracked using John the Ripper:

Passpie: blink182

Privilege Escalation

Using the recovered Passpie password, the stored credentials could be decrypted. The Passpie database contained SSH credentials for both jnelson and root:

jnelson : Cb4_JmWM8zUZWMu@Ys root : p7qfAZt4_A1xo_0x

Root

The recovered root password was used to SSH directly as root:

ssh
$ ssh root@10.129.228.95

After authentication:

whoami root

Root access was successfully obtained.

Key Takeaways

  • Always enumerate WordPress versions, users, and installed plugins.
  • Outdated WordPress plugins can expose critical vulnerabilities such as SQL injection.
  • Configuration files often contain reusable credentials for other services.
  • Enumerate user home directories for credential-management tools such as Passpie.
  • Cracked encryption/passphrase credentials can expose additional accounts, including root.
